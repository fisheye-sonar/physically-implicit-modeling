### Provenance — read this before quoting any number from it

The authors' own distribution channel is **dead**: all four Google Drive folders linked from
[`likenneth/othello_world`](https://github.com/likenneth/othello_world) return 404 (checkpoints,
probe checkpoints, championship dataset, synthetic dataset), verified 2026-08-20 against a
known-public Drive folder as a control.

The checkpoint used here was recovered from the third-party HuggingFace mirror
**`sbentley/othello-world-ckpts`** and then **verified three ways** before use:

1. Loads into their own `GPT` / `GPTforProbeIA` with all 141 keys matched.
2. **Functionally identical to the authors' own TransformerLens conversion**
   (`NeelNanda/Othello-GPT-Transformer-Lens`, `synthetic_model.pth`): max difference in the
   next-move distribution **2.1e-6**, argmax agreement 1.000. The TransformerLens copy is
   LayerNorm-folded and writing-weight-centered, so it is *not* interchangeable with this one for
   activation-space work — it is a check, not a substitute.
3. Reproduces the paper's core property: **99.98%** of predicted probability mass on the legal-move
   set, top-*k* overlap 1.000, over 100 benchmark positions.

`gpt_championship.ckpt` is available from the same mirror and is **not used here**.

## Evaluation set

| code | what | n | provenance |
|---|---|---|---|
| `intervention_benchmark` | (partial game, tile, target colour) triples | **1001** | checked into their repo as `intervention_benchmark.pkl` |

Identified as the paper's **natural** subset (positions reachable by legal play): our reproduced
null-intervention baseline is **2.723**, against their published 2.68 natural / 2.59 unnatural.
Integrity checks, all 1001/1001: the intervened square is occupied, `ori_color` matches the board,
the flip changes the legal-move set, and no case leaves the side to move without a legal move.
The flip changes **2.1 of 64 squares** on average (0.73 gained, 1.37 lost).

## Probe grid

One probe per *(target, family, split, residual point)* — **108 probes**, never shared across
points. Fitting settings are `../othello_gpt/`'s, unchanged: Adam, 200 epochs, batch 4096,
lr 1e-3, 20% held out, inputs standardised inside the probe with a floored per-dim scale.

| axis | levels |
|---|---|
| target | `state` = absolute colour (white/blank/black — **theirs**) · `mine` = blank/mine/theirs relative to the player to move |
| family | `MLP 512 hidden` (**ours** — the width `../othello_gpt/` used) · `MLP 128 hidden` (**theirs** — the width behind `state_tl128`) · `linear` |
| split | `frame` = pooled rows, **their** `random_split` convention · `sequence` = whole games, **our** convention (`harness/ANALYSIS.md` §2) |
| residual point | 0…8, where ℓ is the stream **after** ℓ blocks |

Probe training data: **20,000 synthetic games**, ~1.18 M (activation, board) rows, generated by
their `get_ood_game`. Their own script would have used ~130k championship games; that data is
behind a dead link, and synthetic is this checkpoint's own training distribution.

## Intervention arms

| axis | levels |
|---|---|
| probe family | `MLP 512 hidden` (headline) · `MLP 128 hidden` |
| `n_steps` | 100 (**ours** — `../othello_gpt/`'s default) · 1000 (**theirs** — Appendix G) |
| applied layer `L_s` | 0…8; the write repeats at every point from `L_s` to 8 |
| `beta` | 0.2 — **theirs** (`reg_strg`). Note `../othello_gpt/` ran `beta = 1.0` on discworld |
| `alpha` | swept over 0.002…0.1, relative to each residual point's activation scale; the operating point is chosen by **read-out convergence**, never by the outcome metric |

All arms intervene through **frame-split** probes, matching how theirs were fit; cell [15] repeats
the best arm with sequence-split probes as a robustness check.

## Intervention arms — `controls.ipynb` §4 (added 2026-08-21)

A **second** set of arms, on the same model and the same 1001-case benchmark, using the **linear
mine/theirs frame-split** probes from the grid above (held-out error 0.72% at the best point). These
are *not* the gradient arms above and must not be pooled with them.

| axis | levels |
|---|---|
| mechanism | `add` = Nanda's `x ← x + α·p_d` · `add (target − current)` = the same with `p_target − p_current` · `pinv` = our `pim.editors.probe_steering.inject_state`, **unmodified** |
| points written | all 9 at once, **and** each of 0…8 individually |
| `alpha` | `add` 0.02…0.5 · `pinv` 0.02…6.0. **Reported against `‖Δx‖/‖x‖`, not against α** — the two parameterisations put different write sizes at the same α |
| selection | best α **per cell** on Li error. ⚠ This selects on the outcome metric, which is only admissible because the question is "what is this mechanism's ceiling on this model", not "does it work" |

## Probe controls — `controls.ipynb` §§1–3 (our model, added 2026-08-21)

These run on **`runs/transformers/W16`** and `datasets/4_fixed_refl_inview`, not on anything in
this thread's model section. Implementation: `controls_lib.py`. Probe is `othello_probe.fit_probe`
unchanged (linear = exact `lstsq`; MLP = 512 hidden, 200 epochs), held out **by sequence**, target
= object position (4 dims), residual point 3 unless the sweep varies it.

| axis | levels |
|---|---|
| probe-data scaling | 1,500 / 5,000 / 15,000 / 45,000 / 90,000 train sequences (48k → 2.88M rows), plus a 1,500-sequence **test-split anchor** asserted against the thread's published 0.9349 |
| observation window | 1 / 2 / 4 / 8 / 16 frames of the raw noisy observation, 5,000 sequences, frames t ≥ 15 |
| random init | the identical architecture with untrained weights, **two seeds**, every residual point 0…4 |
