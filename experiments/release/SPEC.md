("When Generative Models Act as Simulators") and nothing else, plus a separately downloaded
artifact bundle (weights, fitted probes, scores, baselines, eval/edit/probe datasets).

## Scope

IN (the paper's objects only):
- Model: Transformer-L (minGPT body): regression head (Rayworld frames), token head (Othello
  moves, the 8-ray token model).
- Probes: linear + MLP-128 decoding probes; inverse map (IM) and its nearest-neighbour
  retrieval control (IM-NN); observation and random-init baselines.
- Editors: PI (zspace only), GS, IM.
- Metrics: Probe Skill, Edit Index (ray-zone for frame models, legal-set / frame-set for
  distribution models), Edit Fidelity, the selection rule (`best_arm`, `best_arm_by_fidelity`),
  seed replicates / SD / CI, prediction loss, Bayes floors.
- Probe targets: Othello mine/theirs. Rayworld regression bases `cartesian` (reported) and
  `frustum` (kept: categorical probes are stored under it, and it stays first in `rw_bases`);
  categorical `appearance-fac` on 128/16/8/5-ray (and their replicates and the token model);
  on the 8-ray MAIN run only: `appearance`, `grid-6x5`, `grid-10x3`, `grid-16x8`,
  `pos@appearance`.
- Environments: the 4 Othello and 8 Rayworld instances above (+ tokens for 8-ray).
- Analyses: reachability (legal/illegal split), two-disc flips, history rewriting, probe-refit
  variance, prediction + Bayes floor, Othello flip rates.
- Demos: `scripts/demos/demo.py`, `scripts/demos/play.py` (need `viz.py`, `interactive.py`).

OUT (delete the code, its call sites, its settings keys and its `__init__` exports):
- editors ND (nanda), nullspace, oracle_overwrite, freeze_interpolation; PI "raw" and "legacy"
  spaces; probes/nullspace; models transformer_s, recurrent, blocks, and every Transformer-S /
  Recurrent branch; figures probe_capacity, probe_targets; rayworld render2d (omni2d);
  soft_render beyond the power-profile path smooth uses; loading.Dataset/DatasetBundle/
  load_dataset; layout v1 migration; the Othello squared-error head (oth_reg / "raw" output
  kind) and `mine_signed`; grid-4x2/8x4/32x16, appearance-d2/-d3/-lat, multi-view categorical
  targets, `full@` snapping; the noisy instance dw-pn04, dw-pair, archive datasets; ND/`mine_signed`
  settings; research-timeline catch-up machinery (env flags that only existed to backfill old
  runs) unless a paper number needs it; `intervention_benchmark.pkl` (Li et al.'s shipped
  cases; the bench uses each instance's own synthesized cases).
- Anything whose only purpose is an experiment, a queue, a driver, a host, or history.

## Writing rules for every shipped file (code, notebooks, JSON, README)

- Module docstring: 1–4 lines saying what the module is. Function docstrings only where the
  behaviour is not obvious, 1–3 lines. Comments only for non-obvious correctness constraints,
  one line each. Keep the few that prevent real bugs (e.g. "parameter order is part of every
  probe-cache key").
- No dates or timestamps anywhere (no `20XX-XX-XX`), no history ("was", "used to", "since",
  "moved from", "ported", "fixed", "bug found"), no "⛔"/"⚠" banners, no references to
  `research/`, `harness/`, `findings`, `GOTCHAS`, `REGISTRY`, `PROGRESS`, `experiments/`,
  `paper_ci`, queues, drivers, hosts, GPUs by box, labs, timezones, or other files that are
  not in the release.
- ⛔ Anonymity: no personal names (the author's name appears in the current code — remove every
  instance and every "(X's pick)"-style attribution), no "the user", no institution, no
  geography, no usernames, no absolute paths, no hostnames/IPs/URLs other than citations of
  public work, no `physically-implicit-modeling`. Third-party credits stay (Li et al.'s MIT
  license in the vendored folder; Karpathy's minGPT credit).
- American spelling in prose. Name things by what they do; use the paper's names (Probe
  Skill, Edit Index, Edit Fidelity, PI, GS, IM, residual point, the variant names).
- Every write path is repo-relative (no absolute paths into `scores.json`/`config.json`).
- Notebooks: minimal, top-to-bottom, one operation per cell, short markdown headers, no
  metric math; shipped WITHOUT outputs and with a generic kernelspec (`python3`).

## The paper items and where the release produces them

Main-text notebook `notebooks/paper_tables.ipynb`:
- Table 1 `tab:decodability` (observation / random-init / trained, Lin + MLP; IM R² at best
  point and at edit point), Table 2 `tab:editability` (Othello, Rayworld continuous, Rayworld
  categorical appearance-fac on the N-ray family; daggers where the seed SD > 0.1), and the
  in-text numbers: IM beats IM-NN by 53.6% on average across Rayworld; seed-SD maxima quoted
  in the results.

Appendix notebook `notebooks/appendix_tables.ipynb`:
- `tab:predictive_skill` (+ "closes at least 99% of the gap"), `tab:seed_spread` (+ the 2.48
  CI multiplier, IM step sizes in SD units, seed means vs 780k values, the fixed-setting check),
  the probe-refit spreads (from `variance.json`), `tab:tokens_decodability`,
  `tab:tokens_editability` (frame-set and mean-frame rows), `tab:additional_rw` (smooth, obs5
  beside standard), `tab:im_by_point`, `tab:categorical` (8-ray targets), `tab:im_vs_nn`,
  `tab:legal_illegal` (from `editability_by_reachability.json` + `reachability.json`),
  `tab:two_flip` (from `two_flip_editability.json`), `tab:fidelity_selected` (+ categorical rows).

Scripts: `scripts/figures/` makes the qualitative edit panels (main-text overview panels and
the appendix grids for Rayworld and Othello), the editability-over-residual-points figure, the
history-rewriting figure, and the two prediction figures. `scripts/` also regenerates every
artifact the notebooks read (data, training, probe fits, replicate member, prediction scores,
Bayes floors, reachability, two-flip, probe-refit variance, Othello flip rates).

Outputs of scripts go to `outputs/` (gitignored), never into the repo tree.
