# templates/

**Cold storage.** These are starting points for *initializing* something new — a project, an
experiment thread, a direction brief, a findings file. They are not part of any session
ritual, no trigger points here, and there is no reason to read them during normal work.

Read one only when you are actually creating the thing it templates.

| file | use when |
|---|---|
| `PROJECT_INIT.md` | standing up the harness in a new project |
| `metrics-registry.md` | starting a new experiment thread that will define metrics or methods |
| `run-registry.md` | starting a thread that will produce more than one run or checkpoint |
| `direction.md` | writing a new candidate-experiment brief |
| `finding.md` | opening a new findings file for a new concept |
| `scratch-note.md` | writing up an experiment's results |
| `gotchas.md` | initializing a project's traps file |
